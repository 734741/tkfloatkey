# TK面板 安装教程

一个 iPhone 上的账号密码 + 2FA 悬浮面板。数据只存本机，不联网。

---

## 你需要准备

- 一台 **Windows 电脑**
- 一根 **iPhone 数据线**
- 你的 **Apple ID**（免费的就行）

---

## 第一步：装 Sideloadly

双击文件夹里的 `Sideloadly安装包.exe`，一路点「下一步」装完。

---

## 第二步：连手机

数据线把 iPhone 连到电脑。

手机上会弹出「**要信任此电脑吗**」，点 **信任**，再输一次锁屏密码。

---

## 第三步：生成 App 专用密码（重要）

直接填 Apple ID 的登录密码会失败，必须用专用密码。

1. 浏览器打开 https://appleid.apple.com
2. 用你的 Apple ID 登录
3. 点「**登录与安全**」
4. 找到「**App 专用密码**」，点 **+**
5. 名字随便填（比如 `sideload`），点「创建」
6. 得到一串像 `abcd-efgh-ijkl-mnop` 的密码，**复制它**

---

## 第四步：安装

1. 双击打开 **Sideloadly**
2. 左上角的 **IPA** 图标点一下，选文件夹里的 `TK面板.ipa`
3. **Apple ID** 填你的账号
4. 点 **Start**
5. 弹出密码框时，粘贴**第三步的 App 专用密码**
6. 等 1-2 分钟，显示 `Done` 就成功了

---

## 第五步：手机上信任

装完后 App 图标是灰的，点不开，正常。

**设置 → 通用 → VPN与设备管理 → 点你的 Apple ID → 信任**

然后再回桌面点开 App。

---

## 第六步：导入账号

打开 App，点中间绿色的「**批量导入 10 组**」。

按下面格式粘贴，每行一个账号：

```
账号----密码----2FA密钥----备注
```

**真实例子：**

```
abcdefg123@outlook.com----pass123456----JBSWY3DPEHPK3PXP----主号
hijklmn456@outlook.com----pass789012----KRSXG5CTMVRXEZLU----小号
```

说明：
- 用**四个短横线** `----` 隔开
- 第 3 段（2FA 密钥）可以留空
- 第 4 段（备注）可以留空，留空就显示账号本身
- 有几行就导入几个槽位，**不限数量**

粘好后点「**导入**」。

---

## 日常使用

点右下角**蓝色圆球**，展开账号列表。

**每一行右边有两个小按钮：**

| 按钮 | 作用 |
|---|---|
| 蓝色人像 | 复制账号 |
| 橙色钥匙 | 复制密码 |

**点数字** 可以展开看详情，账号密码直接显示明文，还有：
- 2FA 验证码（绿色六位数字，30 秒自动刷新）
- 复制账号 / 复制密码 / 编辑 / 删除

**点「新增槽位」** 加一个空槽位，可以在里面手动填。

---

## 2FA 密钥从哪来

**方式一：** TikTok 开启两步验证时选「认证器 App」，页面会显示一串字母，那就是密钥。

**方式二：** 已经有验证器绑定的，在验证器里找「导出 / 显示密钥」。

**方式三：** 扫码后复制整条 `otpauth://totp/...?secret=XXXX` 链接，整条粘到「2FA」栏也能识别。

---

## 7 天过期怎么办

免费 Apple ID 签名 **7 天后失效**，App 会打不开。

**重新走一遍第四步就行**，1 分钟。**数据不会丢**，账号密码还在。

想省事的话，可以买付费开发者账号（$99/年），签一次管一年。

## 常见问题

**Q：导入后账号密码错位了？**
检查分隔符是不是四个短横线 `----`，格式必须是 `账号----密码----2FA----备注`。

**Q：填密码时跳出了我的 Apple ID 账号？**
那是 iOS 系统自动填充，不是你输错了。忽略它，手动输入或粘贴即可。

**Q：App 打开闪退？**
设置 → 通用 → VPN与设备管理，确认已经信任了证书。

**Q：能不能浮在其他 App 上面？**
不能。苹果不允许第三方 App 覆盖在其他 App 上，所有 iOS 设备都一样。用的时候需要切回这个 App 复制。
